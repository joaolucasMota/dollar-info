# Dollar Info 📈

## 📝 Descrição
O Dollar Info é uma aplicação que fornece informações atualizadas sobre cotações de moedas, com foco principal no dólar. A aplicação permite acompanhar em tempo real as variações cambiais e oferece histórico de cotações.

## 🚀 Funcionalidades
- Cotação em tempo real do dólar
- Histórico de variações do dólar
- Comparação com outras moedas
- Gráficos de evolução da cotação
- Alertas de variação de preço

## 🛠️ Tecnologias Utilizadas
- React.js
- Node.js
- Express
- MongoDB
- API de Cotações
- Chart.js para visualização de dados

## ⚙️ Requisitos
- Node.js v14+
- MongoDB
- NPM ou Yarn

## 🎯 Como Usar
1. Após a instalação, acesse a aplicação através do navegador em `http://localhost:3000`
2. Na página inicial, você verá a cotação atual do dólar
3. Navegue entre as diferentes seções para ver gráficos e histórico
4. Configure alertas de preço conforme sua necessidade
